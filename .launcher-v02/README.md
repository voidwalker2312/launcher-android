# Black Hole Launcher v0.2

Minimal AMOLED Android launcher prototype.

- Android HOME role / selectable as the default launcher.
- 5-column scrollable all-apps home surface.
- Pure black background with generated white-outline icons.
- Header search.
- Long-press an app for App Info.
- Menu for default launcher selection and app refresh.
- Offline; no ads, analytics, accounts, or Internet permission.

This first launcher build intentionally does not implement desktop pages, draggable shortcuts, folders, docks, notification dots, or third-party widgets yet.
